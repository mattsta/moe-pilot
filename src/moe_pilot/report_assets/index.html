PAIRED PROTOCOL FOLLOW-UP

Does the checkpoint's native chat wrapper change the result?

Each question is scored twice within the same checkpoint. Question and response-label strings stay fixed. Routing and span loss use the longest exactly identical contiguous question-token span, covering at least 90% of the plain question tokens. This separates context changes from adding role tokens to the routing population.

This exploratory follow-up was selected after the plain-prompt results. It measures protocol sensitivity on this cohort. It does not isolate a training algorithm or evaluate free-form generated answers.

Completed reconstruction

The pinned checkpoint is allenai/OLMoE-1B-7B-0924, revision 6d84c48581ece794365f2b8e9cfb043c68ade9c5. All 16 layers use float32 inference on MPS, selecting 8 of 64 experts per token.

The analysis population contains 100 documents in each of five domains. Loss weights valid next-token targets; document-final positions are excluded. Held-out evaluation includes 420 declared intervention conditions. The original checkpoint revision was absent from the archive, so this is a reconstruction rather than exact checkpoint replication.

New study protocol

Question-content groups are separated into discovery, calibration, and evaluation partitions. MMLU and origin-filtered MMLU-Pro each contribute computing, mathematics, and science. Overlapping MMLU-derived origins are excluded from MMLU-Pro.

Specialists are ranked on discovery routing only. Controls are selected on calibration mass, usage, and function norms. Primary endpoints compare on- versus off-domain specialist-minus-control effects for fixed-routing removal and rerouting, with paired uncertainty and Holm correction. Failed balance prevents causal-specialization claims.

The new study uses 180 evaluation questions, equally weighted across six source × domain cells. Accuracy scores the highest next-token letter among the displayed answer options; normalized choice loss renormalizes over those letters. These are zero-shot subset measurements, not official MMLU or MMLU-Pro scores. Full-text loss includes question, options, and the given answer; its unit differs from loss per question. Exact and near-duplicate grouping separates the study partitions, but does not prove absence of semantic overlap or pretraining contamination. Each training stage has one checkpoint, and the two sources do not represent all tasks.
