# Historical resident-cache diagnostic

`olmoe-0924-resident.json` preserves the full-depth diagnostic completed before
the oversized benchmark was stopped. It records model/input/source identities,
loss parity, and router agreement. Its CPU-reference timing is historical and
is not a recurring release check or a performance comparison.

The record predates the shared-workstation resource policy. It does not
validate the current resource controls or imply that a full resident cache
fits the default budget. The interrupted benchmark produced no accepted new
performance result. Current release validation uses tiny offline fixtures.
